# Entangled Echo — Data Sources Documentation

Entangled Echo uses a multi-tier data ingestion architecture controlled by `DATA_MODE=live|seed|mock`.

## 1. Operating Modes

### `live` Mode (Production / Verified Test Accounts)
- **Instagram Graph API**: Connects via OAuth 2.0 with scopes:
  - `instagram_basic`
  - `instagram_manage_insights`
  - `instagram_content_publish`
- **Facebook Graph API**:
  - `pages_read_engagement`
  - `pages_manage_posts`
- **Competitor Insights**:
  - Uses Meta Business Discovery endpoint to retrieve public profile metrics (follower count, media count, public likes and comments).
  - Note: Private metrics (reach, impressions, saves, shares) are not available for competitor profiles per Meta API policy.

### `seed` Mode (Development, Testing & Evaluation)
- Generated by `scripts/seed/generate.ts` or Python seed engine.
- Generates 12 months of realistic post history with:
  - Hidden ground-truth multiplier matrix (`(day_of_week, hour)`) for evaluation.
  - Media type distribution (Reels, Carousel, Static Image).
  - Hashtag co-occurrence clusters.
  - Realistic reach, likes, comments, shares, saves, and impression logs.
- Stores ground-truth coefficients in `scripts/seed/truth.json` for solver verification.

### `mock` Mode (Offline Unit Tests & Fast Scaffolding)
- Static JSON fixtures loaded from `src/lib/providers/fixtures/` and `tests/fixtures/`.
- Enables running the entire web application and backend offline with zero network calls and zero credentials required.
